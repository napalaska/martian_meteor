# martian_meteor
R exploration of the REMS dataset

This is a brief exploration and case analysis of the Mars Rover Environmental Monitoring System (REMS) dataset  
It includes simple cleaning of the dataset using R code, namely the tidyverse package and ggplot2 package for visualizations  
RMarkdown syntax is used for the report and export to HTML  
The datasets (in RDS and CSV file formats) are housed here as well
